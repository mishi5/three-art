# #256 ノード追加パネルのレイアウト・グルーピング視認性改善

Issue: https://github.com/mishi5/three-art/issues/256

## 背景
ノード追加パネル（#243・#258 で右ドックへ移動）が「ノード名＋説明1行」の縦一列で、52ノードに増えたことでスクロールが長く、カテゴリの境界も弱かった。

## 対応（ユーザ合意）
1. **多列チップ化**: ノード名だけの小さなチップを flex ラップで敷き詰める。説明は行から消し、`title`（「名前 — 説明」）ツールチップへ寄せる → 縦スクロール量を大幅圧縮。
2. **カテゴリのグループボックス**: カテゴリごとに `CATEGORY_COLORS`（#227）の色で左ボーダー＋淡い背景の箱で囲み、境界を明確化。見出しは capitalize。
3. **検索ボックス**: パネル上部に `type=search`。純関数 `matchesQuery`（ノード名・説明の部分一致・大小無視・空クエリは全件）で絞る。`buildNodeAddSections(defs, allowedTypes, query)` に query 引数を追加し、**#258 の互換フィルタと併用可**（互換で絞った集合にさらに検索が効く）。空カテゴリはセクションごと非表示、全滅時は `search-empty`（検索）/ `filter-empty`（互換フィルタ）を出し分け。

## 非対象 / 既存挙動維持
- チップのクリック追加・エッジドロップ後の onPick・自動クローズ（#228）・ピン・フィルタ機構（#258）は不変。
- パネル幅（PANEL_W・side-dock 共通）は変更せず、その幅で複数列に収まる。

## テスト
純関数 `matchesQuery` 4件・DOM（チップ/title・グループボックス・検索絞り込み・該当なし）を追加。全1443件パス。
