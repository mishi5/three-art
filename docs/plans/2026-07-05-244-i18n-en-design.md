# #244 UI 言語切り替え（日本語 / 英語）設計

対象 Issue: https://github.com/mishi5/three-art/issues/244

## 目的

node-vj の UI クローム文言を日本語 / 英語で切り替えられるようにする。
既定は**日本語**（既存ユーザの見た目を変えない）。

## 方針

- 軽量 i18n モジュール `src/apps/node-vj/i18n.ts` を新設（外部ライブラリなし）。
  - カタログ: `{ [key]: { ja: string; en: string } }`。
  - `t(key, vars?)`: 現在言語の文言を返す。`{name}` 形式の簡単な補間をサポート。
  - フォールバック: en が未翻訳なら ja へ、未知キーはキー名をそのまま返す（壊れない）。
  - 現在言語はモジュール内状態（`setLang` / `getLang`）。テスト時は既定 ja のまま。
  - 純関数部分（`translate` / `interpolate`）をテスト対象にする。
- 言語設定は prefs（#229 の localStorage prefs）に `lang: "ja" | "en"`（既定 `"ja"`）で永続化。
  - `Prefs` 型・`DEFAULT_PREFS`・`parsePrefs` の検証を各 1 行追加＋テスト（#229 のパターン）。
- 切替 UI は設定パネルの「言語 / Language」セクション（#229 操作モードと同じ 2 択ボタン UI）。
  - クリックで prefs 保存 → `location.reload()` で反映（**ライブ再構築はしない**・ユーザ決定）。
  - ボタン説明に「切替時に再読み込みします / Reloads on switch」を明記。
- `main.ts` 起動時、UI 構築（NodeEditor 生成・サイドドック構築）より**前に** prefs を読んで
  `setLang()` する。モジュールロード時に評価される定数（設定パネルの選択肢・ヘルプ本文）は
  カタログキーを保持し、mount / 呼び出し時に `t()` で解決する形へ変更する。

## スコープ（v1 = UI クローム）

`t()` 化する領域:

- ツールバー（`editor/NodeEditor.ts`）: 出力値トグル・`?` ボタン title
- ヘルプポップアップ全文（`editor/help-content.ts` の全セクション・全項目）
- サイドドック（`editor/side-dock.ts`）: ピン留め・パネルを閉じる
- アセットパネル（`asset/asset-panel.ts`）: タイトル・追加・空表示・使用量・削除・トースト
- シーンパネル（`scene/scene-panel.ts`）: タイトル・追加・出力バッジ/トグル・複製・削除
- クリップボードパネル（`editor/clipboard-panel.ts` / `editor/node-clipboard.ts`）:
  タイトル・ヒント・空表示・件数表示・現在バッジ・clipLabel
- ノード追加パネル（`editor/node-add-panel.ts`）: タイトル
- コントロールパネル（`editor/controls-panel.ts` + `main.ts` の各セクション）:
  入力 / 出力・録画 / シーン / プロジェクトの見出し・全ボタン・音声デバイス選択・トースト
- グラフ/プロジェクト保存読込（`editor/graph-io-controls.ts`）: ボタン・placeholder・トースト
- 設定パネル（`editor/settings-panel.ts`）: 操作モード（標準/クラシック）・AI ブリッジ・
  接続状態表示・ヒント・新設の言語セクション
- コンテキストメニュー（`editor/NodeEditor.ts`）: ラベル編集/削除・ノード追加・複製・削除・
  ノード名/グループ名編集・シーン選択・パッド操作
- パッドオーバーレイ（`editor/pad-overlay.ts`）: 閉じる・ヒント・パッド title・右クリックメニュー
- canvas 描画のノード内文言（`editor/layout.ts` / `editor/NodeEditor.ts`）:
  ファイル未選択・タップ録音のボタン/ステータス・ランダムボタン・シーン未選択・ラベル既定文言
- `main.ts`: (不明なシーン) 表示

## スコープ外（将来 Issue で段階対応）

- **ノード定義の文言**（`nodes/` 配下の `description`・ポート説明・param ラベル）。
  `getNodeCatalog` 経由で AI API にも渡る文言のため、カタログ生成との整合を含め別 Issue で対応する。
  ノード追加パネルの各行説明・メニューのツールチップ（#203）はこの description を表示しているため、
  現状は言語設定に関わらず日本語のまま。
- ノード追加パネルのカテゴリ見出し（registry の category id を CSS capitalize で表示・元から英語）。
- `console.warn` / `console.log` 等の開発者向けログ。
- データ層のエラーメッセージ（`scene/project-file.ts` の YAML 解析エラー・warnings、
  `scene/scene-manager.ts` の内部エラー等）。トースト内に `e.message` として露出することが
  あるが、テストで文言比較されており量も多いため v1 では対象外。
- 「■ Stop」「ON/OFF」「?」など元から言語非依存の表記。

## テスト

- `i18n.test.ts`: translate（ja/en・フォールバック・未知キー）・interpolate・setLang/getLang・
  カタログ全キーの ja/en 非空。
- `prefs.test.ts`: `lang` の既定値・読み取り・不正値フォールバック・部分更新の独立性を追加。
- 既存テスト（help-content / help-popup / layout / node-clipboard 等の日本語文言比較）は
  既定言語 ja のまま `t()` が同一文字列を返すため無変更でパスする。

## 動作確認（手動）

- 設定パネル →「言語 / Language」→ English クリックで自動リロードされ、UI クロームが英語になる。
- 再読み込み後も英語が保持される。日本語へ戻すと従来表示に戻る。
- 既定（初回・保存なし）は日本語のまま。
