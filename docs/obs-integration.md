# OBS 連携（クリーンフィード）

node-vj のライブ出力（UI なしのクリーンフィード）を OBS のブラウザソースへ取り込む手順。
（#283: https://github.com/mishi5/three-art/issues/283 ）

## 仕組み

- メインタブ（node-vj 本体）が出力 canvas の `captureStream()` を WebRTC で配信し、
  専用ページ `/obs.html` が受信して映像のみ全画面表示する。
- **OBS のブラウザソースは OBS 内蔵の別ブラウザ（CEF）で動く**ため、シグナリングは
  dev サーバの **WS リレー（`/cf-signal`・送信元以外へそのまま転送）** 経由で行う。
  BroadcastChannel はブラウザを跨げないため、WS エンドポイントが無い環境（静的 dist 配信等）
  向けの**同一ブラウザ内フォールバック**として併用する。
  したがって **OBS で使う場合は dev サーバ（`bun run dev:vj` / `bun run bridge:up`）経由での
  利用が前提**。
- WebRTC 自体は同一マシン内で直接張られる（`iceServers: []`・host candidate のみ）。STUN は不要。
- `/obs.html` は複数開ける（OBS ＋確認用ブラウザタブなど。viewer ごとに接続を張る）。
- メインタブが閉じている/リロード中でも `/obs.html` は 2 秒間隔で再接続を試み続けるので、
  **どちらを先に開いてもよい**。

## OBS 側の設定手順

1. node-vj の dev サーバを起動する（`bun run dev:vj` または `bun run bridge:up`。既定 port 3000）。
2. ブラウザで node-vj 本体（例: `http://localhost:3000/` ）を開く。
   - コントロールパネル「出力・録画」の「📡 OBS 用 URL をコピー」ボタンでクリーンフィードの
     URL（例: `http://localhost:3000/obs.html` ）をコピーできる。配信中はボタンに接続数が出る。
3. OBS で「ソース」→「＋」→「ブラウザ」を追加し、以下を設定する:
   - **URL**: コピーした URL（例: `http://localhost:3000/obs.html` ）
   - **幅 / 高さ**: 1920 × 1080（配信中の出力 canvas は 1920×1080 で描かれる。
     映像は object-fit: contain なのでソース側のアスペクト比 16:9 に合わせると余白が出ない）
   - **「OBS を介して音声を制御する（Control audio via OBS）」にチェック**（音声を使う場合。下記参照）
4. メインタブ側でグラフを Screen に接続していれば、数秒以内に OBS へ映像が流れる。

## 音声

クリーンフィードには **音声トラックも載っている**（グラフの AudioOutput ノードの音、録画 #179 と
同じ経路）。`/obs.html` の `<video>` は autoplay 許可のため muted だが、これはページ内のスピーカー
出力を止めるだけで、**OBS のブラウザソースで「OBS を介して音声を制御する」を有効にすれば音声も
取り込める**（音声ミキサーに「ブラウザ」ソースが現れる）。

- 音が来ない場合: メインタブで一度ページ内を操作（クリック）して AudioContext を起こす
  （「▶ 入力開始」や再生ボタンなど任意の操作でよい）。ブラウザの自動再生制限のため、
  ユーザ操作があるまで音声グラフが動かないことがある。
- グラフに AudioOutput ノードが無い構成では音声は無音（keep-alive の無音サンプルのみ）。
  その場合は従来どおり OBS 側でデスクトップ音声キャプチャを使う。

## トラブルシュート

| 症状 | 対処 |
| --- | --- |
| 「node-vj の起動を待っています…」のまま | ① メインタブ（node-vj 本体）が開いているか確認。② メインタブと OBS のブラウザソースが**同じサーバ（同じ host:port）**を指しているか確認（ポート違い・localhost と 127.0.0.1 の混在に注意）。③ dev サーバ（dev:vj / bridge:up）経由か確認——静的 dist 配信には WS シグナリングが無く、OBS（別ブラウザ）へは届かない |
| 映像が止まる/カクつく | メインタブを最小化しても keepAlive で描画は継続するが、マシン負荷が高いとフレームが落ちる。プレビュー拡大や録画の併用を減らす |
| メインタブのリロード後に映像が戻らない | 数秒待つ（viewer は 2 秒間隔で自動再接続する）。戻らなければ OBS のブラウザソースのプロパティで「キャッシュを更新（ページを再読み込み）」 |
| 音が来ない | ブラウザソースの「OBS を介して音声を制御する」を有効にする。メインタブで一度クリック操作をして AudioContext を起こす。グラフに AudioOutput があるか確認する |
| 複数の node-vj タブを開いている | publisher が複数になり最後に offer を返したタブが勝つ。メインタブは 1 つだけ開く |
| OBS の映像がぼやける | ブラウザソースの幅/高さを 1920×1080 にする（小さいと縮小され、拡大時にぼやける） |
